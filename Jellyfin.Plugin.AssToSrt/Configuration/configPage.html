ASS to SRT

Creates an SRT copy of ASS/SSA subtitles, next to the video, so that clients which cannot display ASS (Android TV, Fire TV, Roku...) play the video directly instead of asking the server to burn the subtitles in. The ASS tracks are kept: the SRT is only added.

Libraries

Leave everything unchecked to process every video library.

Options

A video added to the library is converted about a minute after Jellyfin has analysed it. Otherwise the conversion only runs with the scheduled task (every night at 4:00).
Forced ASS tracks (only the foreign-language lines) become ".forced.srt" files.
These tracks only translate on-screen signs and songs and rely on ASS positioning: they are rarely useful as SRT.
Colors, fonts and karaoke effects are always removed.
